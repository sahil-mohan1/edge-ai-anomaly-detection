# ⚡ Embedded Edge Deployment (Firmware)

Welcome to the firmware deployment directory. This folder contains the physical execution layer for the smart water-level anomaly detection node. The firmware is built in C/C++ specifically for the **STM32WLE5 (LoRa-E5)** microcontroller.

By leveraging **STMicroelectronics X-CUBE-AI**, this firmware executes the neural network trained in the `ml/` directory directly on the edge.

## 🚀 Core Capabilities

- **On-Device AI Inference**: Runs the heavily optimized, dual-branch AR-MLP model directly on the MCU. It performs real-time classification of hardware faults and autoregressive reconstruction of missing sensor data within a 3-6 ms inference window.
- **HLK-LD2413 Sensor Integration**: Directly interfaces with the 24GHz mmWave radar via UART, parsing real-time distance metrics and native hardware status bytes.
- **LoRaWAN Payload Optimization**: Constructs a highly compressed, custom binary payload containing the AI-validated distance, error status, battery voltage, and historical logs.
- **Power Efficiency**: Designed to operate within the strict power and memory limits (256 KB Flash, 64 KB SRAM) of the LoRa-E5 module, allowing for extended battery life in remote off-grid deployments.


## 🛠️ Getting Started & Flashing

### 1. Prerequisites
- Install [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html).
- Ensure you have an ST-LINK programmer connected to your LoRa-E5 module via SWD.

### 2. Building the Project
1. Open **STM32CubeIDE**.
2. Go to **File -> Import...**
3. Select **General -> Existing Projects into Workspace** and click Next.
4. Browse to the `firmware/E5_hlk_RLS/STM32CubeIDE/` directory and select it.
5. Click **Finish**.
6. **Note**: Ensure that the Python ML pipeline has successfully placed the required weights in `firmware/embedded_exports/` before building.
7. Click the **Hammer Icon** (Build Project).

### 3. LoRaWAN Network Server Setup
If you are connecting this node to a ChirpStack or TTN gateway, you will need to decode the custom binary payload. 
Copy the contents of `firmware/E5_hlk_RLS/chirpstack_codec.js` and paste it into the **Payload Codec** section of your device profile on the network server.
