# firmware

STM32 / embedded firmware for the water-level anomaly detection sensor node.

## Structure

```
firmware/
├── E5_hlk_RLS/          # STM32WLE5 LoRaWAN node (STM32CubeIDE project)
│   ├── Core/            # Application code (main, sensors, LoRaWAN stack)
│   ├── Drivers/         # HAL + BSP drivers
│   ├── LoRaWAN/         # LoRaWAN middleware
│   ├── Middlewares/     # STM32 middleware
│   ├── chirpstack_codec.js  # ChirpStack payload decoder
│   └── tools/           # Helper scripts
├── embedded_exports/    # C/C++ model headers + test harness generated from Python
│   ├── mlp_weights.h
│   ├── custom_model.h
│   ├── realtime_mlp_outage_tester.cpp
│   └── ...
└── include/             # Shared C headers (test datasets etc.)
```

## Build

Open `firmware/E5_hlk_RLS/STM32CubeIDE/` in STM32CubeIDE and build normally.
The `embedded_exports/` headers are generated by the Python side — see `ml/scripts/embedded_exports/`.
